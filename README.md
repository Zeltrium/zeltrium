# zeltrium.com

Static site for Zeltrium, hosted on GitHub Pages (custom domain in `CNAME`).

- `index.html` — landing page; `styles.css`, `script.js` — styles and behaviour
- `imprint.html`, `privacy.html`, `contact.html`, `license.html` — legal and info pages
- `assets/lottie/preview.dat` — all 30 animations for the on-page previews (the pack v1.0 dark set), lightly encoded, not a download
- `assets/js/lottie_light.min.js` — lottie-web light player (MIT, see `lottie-web-LICENSE.md`)
- `assets/fonts/` — Bricolage Grotesque, Onest, JetBrains Mono, Latin subset (SIL OFL)
- `assets/brand/` — logo and symbol SVGs
- `downloads/zeltrium-free-5.zip` — free sampler (5 animations, dark and light sets), downloaded right after sign-up and linked in the welcome email

No cookies, no analytics, no third-party scripts. The only outside request is the
free-pack form, which posts the email address to MailerLite (double opt-in).
