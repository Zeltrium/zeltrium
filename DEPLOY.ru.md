# Чек-лист по запуску

## 0. Локальная проверка (важно!)
Если открываешь `index.html` двойным кликом — в адресной строке будет `file:///...`.
При таком открытии браузер **блокирует загрузку локальных JSON-файлов** (это защитное
ограничение CORS), поэтому анимации не подтянутся и вместо них будет значок-предупреждение.
Это не баг вёрстки и не проблема с именами файлов — так работает браузер с `file://`.

Чтобы проверить локально по-настоящему, нужен локальный сервер:
- **Если есть VS Code** — поставь расширение "Live Server", открой папку `landing-page`,
  правой кнопкой на `index.html` → "Open with Live Server".
- **Если есть Python** — в терминале, в папке `landing-page`:
  ```
  python -m http.server 8000
  ```
  и открой в браузере `http://localhost:8000`.

После публикации на GitHub Pages эта проблема исчезает сама — сайт будет открываться
через `https://`, а не `file://`, и всё подтянется без локального сервера.

## 4. Привязать домен
В настройках DNS у `zeltrium.com` добавить:
- `A`-записи для `@`, указывающие на IP GitHub Pages:
  `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
- `CNAME`-запись для `www`, указывающую на `ТВОЙ_ЮЗЕРНЕЙМ.github.io`

Файл `CNAME` уже лежит в репозитории — GitHub Pages подхватит его сам, как только
DNS обновится (может занять от пары минут до нескольких часов).

## 5. Проверить перед тем, как давать ссылку
- Заполнить форму своим настоящим email — убедиться, что письмо дошло в Formspree
  и появилась кнопка скачивания.
- Нажать кнопку скачивания — убедиться, что архив реально скачивается и корректно распаковывается.
- Нажать кнопку Gumroad — убедиться, что ведёт на нужный товар.
- Проверить `imprint.html`, `privacy.html`, `contact.html` — ссылки в футере работают
  с любой страницы, кнопка mailto открывает почтовый клиент.
- Открыть с телефона — трафик из био почти весь будет мобильный.
